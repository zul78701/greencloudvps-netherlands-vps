## 下单前必须知道的四条限制

这部分是多数推荐文章不会写的，但每一条都可能直接影响你的钱包。

1. **活动机不退款**。它家搞过 168 美元/3 年的存储促销机，社区测评明确提示这类活动机不予退款，宣传 CPU 与实际到手也常对不上。对低价促销机，到手第一件事是核实实际配置和 IP 状况。
2. **7 天退款只保首单，且付款方式有例外**。VPS 有 7 天退款保证，但仅限首次购买，比特币支付不支持退款。想留退路的，用 PayPal 或信用卡付款更稳妥。

4. **超售痕迹**。有评测指出其部分低价大盘机“从 CPU 跑分看超售比较明显”，官方口径则是“个别时期存在超售”。买 15 美元档的机器就该有这个心理预期：这个价位买的是价格和带宽，不是独享性能。
